# Reporte comercial de métricas del dashboard

Este dashboard permite visualizar en un solo lugar la información clave del negocio: ventas, cobranza, productos, clientes, campañas de marketing y operación comercial. La idea es que el cliente pueda tomar decisiones rápidas sin depender de planillas dispersas ni análisis manuales.

## Qué valor entrega

El sistema ayuda a responder preguntas concretas del día a día:

1. Cuánto vendió el negocio.
2. Cuánto dinero entró realmente.
3. Qué productos generan más facturación.
4. Qué productos se venden más en cantidad.
5. Qué clientes compran más.
6. Qué campañas publicitarias generan resultados.
7. Qué oportunidades hay para vender mejor, cobrar mejor y optimizar stock.

## Panel financiero

El módulo financiero muestra una foto clara de la salud económica del negocio.

### Métricas principales

| Métrica | Qué le muestra al cliente |
|---|---|
| Ventas totales | Cuánto facturó el negocio en el período seleccionado. |
| Pagos recibidos | Cuánto dinero ingresó efectivamente. |
| Comprobantes emitidos | Cuántas ventas o documentos comerciales se generaron. |
| Ticket promedio | Cuánto gasta en promedio cada cliente por compra. |
| Efectividad de cobranza | Qué porcentaje de lo vendido ya fue cobrado. |
| Ventas por día | Cómo evolucionaron las ventas durante el período. |
| Mejores días de venta | Qué días tuvieron mayor movimiento comercial. |
| Top productos | Qué artículos generaron más ingresos. |

### Para qué sirve

Este panel permite detectar rápidamente si el negocio está vendiendo bien, si está cobrando a tiempo y cuáles son los días o productos que más empujan la facturación.

## Comparación de ventas

El dashboard permite comparar las ventas actuales contra otros períodos.

### Qué compara

| Comparación | Qué permite ver |
|---|---|
| Período actual vs período anterior | Si el negocio creció o cayó respecto al período previo. |
| Período actual vs año anterior | Si el rendimiento mejoró frente al mismo momento del año pasado. |
| Ventas diarias comparadas | En qué días hubo picos, caídas o cambios importantes. |
| Variación porcentual | Cuánto subieron o bajaron las ventas. |
| Cantidad de comprobantes | Si el cambio vino por más ventas o por ventas de mayor valor. |

### Para qué sirve

Ayuda a entender si una mejora viene por más clientes, por tickets más altos, por estacionalidad o por acciones comerciales específicas.

## Métodos de pago

El sistema muestra cómo pagan los clientes.

### Métricas disponibles

| Métrica | Qué le muestra al cliente |
|---|---|
| Medios de pago más usados | Si predomina efectivo, tarjeta, transferencia u otro medio. |
| Monto cobrado por medio de pago | Cuánto dinero ingresó por cada método. |
| Participación de cada método | Qué porcentaje representa cada forma de cobro. |
| Cantidad de operaciones | Cuántas veces se usó cada medio. |

### Para qué sirve

Permite entender el comportamiento de pago de los clientes y tomar decisiones sobre promociones, financiación, recargos, descuentos o acuerdos con medios de pago.

## Productos y catálogo

El módulo de productos permite saber qué artículos mueven realmente el negocio.

### Métricas principales

| Métrica | Qué le muestra al cliente |
|---|---|
| Facturación por producto | Qué productos generan más dinero. |
| Unidades vendidas | Qué productos se venden más en cantidad. |
| Productos distintos vendidos | Cuántos artículos tuvieron movimiento. |
| Producto líder por facturación | El artículo que más ingresos generó. |
| Producto líder por unidades | El artículo que más rotación tuvo. |
| Participación del top 5 | Cuánto depende el negocio de sus productos principales. |
| Búsqueda por producto | Permite analizar un artículo específico por nombre o código. |

### Para qué sirve

Este módulo ayuda a decidir qué productos reponer, cuáles promocionar, cuáles tienen alta rotación y cuáles pueden estar ocupando espacio sin aportar ventas.

## Pareto 80/20

El análisis Pareto identifica los productos más importantes del negocio: aquellos que explican la mayor parte de la facturación.

### Métricas principales

| Métrica | Qué le muestra al cliente |
|---|---|
| Productos clave | Qué artículos concentran la mayor parte de los ingresos. |
| Participación de cada producto | Qué porcentaje aporta cada artículo a la facturación. |
| Participación acumulada | Cómo se va formando el 80% de la facturación. |
| Productos que entraron al grupo clave | Artículos que ganaron importancia. |
| Productos que salieron del grupo clave | Artículos que perdieron relevancia. |
| Productos que se mantienen | Artículos estables dentro del grupo más importante. |
| Comparación contra período anterior | Cómo cambió el mix de productos. |
| Comparación contra año anterior | Qué cambió frente al mismo período del año pasado. |

### Para qué sirve

Permite enfocar la gestión en los productos que realmente sostienen el negocio. Es especialmente útil para compras, stock, exhibición, promociones y negociación con proveedores.

## Clientes

El dashboard permite analizar clientes y oportunidades comerciales.

### Métricas y datos disponibles

| Métrica | Qué le muestra al cliente |
|---|---|
| Clientes con venta confirmada | Contactos que ya compraron. |
| Leads pendientes | Personas que consultaron pero todavía no compraron. |
| Estado de llamada | Si el contacto ya fue llamado o no. |
| Estado de venta | Si el contacto terminó comprando. |
| Mejores clientes | Ranking de clientes que más facturan. |
| Exportación de clientes | Posibilidad de descargar la base para seguimiento comercial. |

### Para qué sirve

Ayuda a ordenar el seguimiento comercial: separar clientes reales de interesados, priorizar contactos, medir conversión y mejorar la gestión de ventas por WhatsApp o canales digitales.

## Rentabilidad y márgenes

El sistema también puede responder consultas sobre rentabilidad desde el asistente inteligente.

### Métricas disponibles

| Métrica | Qué le muestra al cliente |
|---|---|
| Margen promedio | Rentabilidad general del período. |
| Productos con mejor margen | Artículos que dejan mayor ganancia relativa. |
| Productos con peor margen | Artículos que conviene revisar por baja rentabilidad. |
| Ganancia estimada | Resultado económico asociado al margen. |

### Para qué sirve

Permite vender con más inteligencia, no solo vender más. Ayuda a detectar productos que facturan mucho pero dejan poco margen, y productos que conviene impulsar porque son más rentables.

## Operación comercial

### Métricas disponibles

| Métrica | Qué le muestra al cliente |
|---|---|
| Ventas por hora | En qué horarios se vende más. |
| Horarios pico | Momentos de mayor demanda. |

## Marketing y Meta Ads

El módulo de marketing mide el rendimiento de campañas de Facebook e Instagram.

### Métricas principales

| Métrica | Qué le muestra al cliente |
|---|---|
| Inversión publicitaria | Cuánto se gastó en anuncios. |
| Impresiones | Cuántas veces se mostraron los anuncios. |
| Alcance | A cuántas personas llegaron las campañas. |
| Clicks | Cuántas personas hicieron clic. |
| Conversaciones iniciadas | Cuántos chats o consultas generaron los anuncios. |
| CAC | Cuánto cuesta generar una conversación o potencial cliente. |
| CTR | Qué porcentaje de personas hizo clic al ver el anuncio. |
| CPC | Cuánto cuesta cada clic. |
| CPM | Costo por cada mil impresiones. |
| Frecuencia | Cuántas veces, en promedio, una persona vio el anuncio. |

### Para qué sirve

Permite saber si la inversión publicitaria está generando consultas reales y si conviene aumentar presupuesto, ajustar anuncios o pausar campañas.

## Recomendaciones automáticas de campañas

El dashboard no solo muestra datos: también clasifica campañas y conjuntos de anuncios según su rendimiento.

### Acciones sugeridas

| Acción | Qué significa |
|---|---|
| Escalar | La campaña funciona bien y podría recibir más presupuesto. |
| Mantener | Tiene rendimiento aceptable y conviene seguir monitoreando. |
| Revisar creatividad | El anuncio puede necesitar nuevos textos, imágenes o mensajes. |
| Saturación | La audiencia vio demasiado el anuncio y puede estar perdiendo efectividad. |
| Pausar | La campaña no está justificando la inversión. |

### Para qué sirve

Le da al cliente una lectura accionable, no solo números. Esto facilita tomar decisiones de marketing incluso sin ser especialista en publicidad digital.

## Asistente inteligente de negocio

El proyecto incluye un asistente de inteligencia artificial que permite consultar datos en lenguaje natural.

### Ejemplos de preguntas que puede responder

1. Cuánto vendí este mes.
2. Qué productos generaron el 80% de mi facturación.
3. Cuáles fueron mis mejores clientes.
4. Qué campaña de Meta Ads debería pausar.
5. Cuál fue mi ticket promedio.
6. Qué productos se vendieron más en unidades.
7. Cuál fue mi margen promedio.
8. A qué hora vendo más.
9. Cómo me fue contra el mes anterior.
10. Cómo me fue contra el año pasado.

### Para qué sirve

Permite que el cliente haga preguntas de negocio sin tener que navegar todos los paneles. El asistente interpreta fechas, compara períodos y entrega respuestas claras con foco comercial.

## Beneficios para vender el producto

### Para el dueño o gerente

Le da control sobre ventas, cobranzas, productos y campañas desde un solo lugar. Puede tomar decisiones sin esperar reportes manuales.

### Para el equipo comercial

Permite identificar clientes, leads, oportunidades de seguimiento y productos prioritarios.

### Para marketing

Muestra qué campañas generan conversaciones reales y qué acciones conviene tomar para mejorar el retorno de la inversión.

### Para compras y stock

Ayuda a saber qué productos reponer, cuáles tienen alta rotación y cuáles concentran la facturación.

## Resumen comercial

Este dashboard convierte datos dispersos en decisiones concretas. El cliente puede ver cuánto vende, cuánto cobra, qué productos sostienen el negocio, qué campañas funcionan y dónde hay oportunidades de mejora.

En términos comerciales, el producto se puede presentar como una herramienta de inteligencia de negocio para ferreterías y comercios que necesitan vender mejor, controlar su operación y optimizar su inversión publicitaria.
